# 时间相关 (s,S) 基准（骨架）

状态：**未实现**。本目录只保留接口、配置草案和方法说明，不产出任何结果。

## 计划口径

本目录将来**自包含** simulator / policy / evaluation（不共享 `common/` 的
仿真器；可参考 `ss_static/` 的实现复制/改造）。`common/` 只提供模型加载、
配置、基线读取和通用配对统计。只替换订货规则：

- 把时间无关的 `s_r, S_r` 换成 `s_{r,k}, S_{r,k}`，`k=1..K` 为时间分段
  （建议 `K=6` 或 `12`，分段常数，避免 60×5 个自由参数过拟合）；
- 或参数化为少量节点 + 线性插值；
- 履约规则与 `ss_static` 保持一致（先全仓本地替换，再按优先级跨仓；
  无主动调拨），这样差异主要来自“时间适应”；
- 标定沿用根目录 `config/compare.toml` 的标定/验证路径划分；
  参数只在标定/验证上选，测试仍用基线 npz 的 2000 条 `scene`；
- 结果目录 `results/ss_timevarying/`，报告格式与 `ss_static` 对齐。

## 预期贡献

时间相关策略可以刻画：早期机队全新、失效少 → 低目标库存；后段失效爬坡
→ 提高 `S`；末期 → 收缩订货。它应优于时间无关 `(s,S)`，但仍弱于 SDDP
（后者还使用健康等级状态与主动调拨）。
